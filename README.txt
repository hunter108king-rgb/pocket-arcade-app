POCKET ARCADE (flat version: is folder mein koi subfolder nahi hai)

1. GitHub par NAYI repository banao (naam: pocket-arcade-app).
2. "uploading an existing file" dabao.
3. Is folder ki SAARI files select karo (Ctrl+A) aur upload box mein drag karo.
   (PASTE-THIS-build.yml.txt aur README.txt bhi upload ho jaye to koi dikkat nahi.)
4. "Commit changes" dabao.
5. Repository mein "Add file" -> "Create new file" dabao.
   Naam ki jagah likho:  .github/workflows/build.yml
   Bade box mein PASTE-THIS-build.yml.txt ka poora text paste karo.
   "Commit changes" dabao.
6. "Actions" tab mein build chalega (4-6 minute). Green hone par job kholo,
   neeche Artifacts se PocketArcade-APK download karo, zip kholo, app-debug.apk install karo.
